# Save Point

Application web (un seul fichier HTML) pour suivre son temps de jeu vidéo : solo, multi, combat.
Les données restent dans le navigateur de l'appareil ; aucune n'est envoyée ni publiée.

- Fichier de l'app : `test.html`, gardé sous ce nom (le renommer casserait l'icône de l'écran d'accueil et viderait l'app).
- Sauvegarde : depuis Plus, « Enregistrer un fichier de sauvegarde » (fichier `.json`, jamais à publier ici).
- Polices : voir `FONTS.md`, ainsi que `OFL.txt` et `LICENSE-2.0.txt` pour les textes de licence.

## Statut

Projet personnel et non commercial : pas de publicité, pas de collecte de données, pas de vente. Il est publié sur un dépôt public uniquement pour être hébergé gratuitement. Les polices appartiennent à leurs auteurs (voir `FONTS.md`).
